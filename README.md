# Bienvenido a MeaCulpa

**MeaCulpa** es una plataforma web de rol de fantasía: un mundo persistente donde creas personajes, acumulas oro, comercias, te unes a gremios y vives (o mueres) en partidas dirigidas por un Dungeon Master. Aquí cada decisión cuenta, cada moneda tiene dueño y la muerte de un personaje es algo muy real.

Si acabas de llegar: bienvenido, aventurero. Este documento te pone en contexto.

##  ¿Qué es MeaCulpa?

MeaCulpa es el compañero digital de una campaña de rol de mesa. Centraliza todo lo que en una mesa tradicional vive en hojas de papel y en la memoria del DM:

- **Personajes persistentes** — cada usuario puede crear personajes con nivel (hasta 20), fuerza, bolsa de objetos con capacidad limitada, extremidades que se pueden perder y un estado de vida real: si tu personaje muere, muere. Existe historial de muertes y mecánicas de revivir.
- **Economía de oro** — el oro es un recurso protegido a nivel de base de datos: transacciones auditadas, impuestos que el admin puede cobrar en masa, y sin trampas posibles desde el cliente.
- **Tiendas y comercio** — tiendas gestionadas por el admin con artículos y precios, más comercio directo entre jugadores. Las compras se bloquean mientras estás en partida.
- **Equipamiento** — armas (incluidas a dos manos), capas, cinturones, anillos (tres slots), gemas y sockets para mejorar el equipo.
- **Conjuros** — registro de conjuros conocidos por personaje, con buscador sobre un catálogo completo.
- **Gremios** — únete a un gremio y comparte recursos a través del baúl común.
- **Partidas** — salas de juego con vista de DM y de jugador, partidas públicas con sistema de unión, reglas y metadatos propios, y la mecánica *sleep or die*: descansa o atente a las consecuencias.
- **Dados** — módulo de dados visual con recompensas configurables, tablas de botín (LUT) y subtablas de oro.
- **Ruleta de premios** — ruleta con pools de premios auditados, giros pagados con oro o con dinero real vía PayPal.
- **Panel de administración** — gestión de usuarios, personajes (incluido matarlos), oro, objetos, tiendas, impuestos, partidas, dados y ruleta.





*Que los dados te sean favorables. Y si no lo son... mea culpa.* 🎲
